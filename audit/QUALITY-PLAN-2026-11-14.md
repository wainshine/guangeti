## 1. 跨线质量卡（所有版本必须交）

固定字段：
1. real-only 指标 + n；2. full-coverage 指标 + n；
3. 分层：real / GAN / hardtail / ribbon，各层独立数字；禁止只报字体平均；
4. 标签来源、抽样 n、错标率 + 95% CI；
5. 盲审：用**缺笔率 / 结构崩坏率**为主，错字率仅在有可靠真值时报；分层配额与盲判人；
6. 同字集基准：明确 val 字集、floor/GAN 同集数字；**跨字集禁止相除**；
7. 孔洞两栏：`原图有孔而字体没有=真损失` vs `原图同样开口=风格`；对比必须用 source mask；
8. 发布声明：哪些是继承值、哪些不可比、发布 QA 与质量门分开。

同字集基准做法（写死）：
```
pairs_multi 按「字」切分：train 字用于训练；val 字（如 300 个，各有 2–4 个真迹样本）
在 val 字上同时算：
  floor = 两个真迹样本之间的 chamfer（同字集）
  gan   = GAN 输出 vs 另一真迹样本的 chamfer（同字集）
两者同字集、同度量，才可相减。
```
B 的 clean 629 无第二样本，**不能做同集地板**；不得再写“距地板 x%”。

**固定回归资产（三线统一，2026-11-14 三线复核后新增）：**
- 每线固定 100 字表 `chars_100.txt`（real/GAN/ribbon 分层，入库），每版同表重出；另出随机 100 字仅作盲审，不替代固定表；
- **版本对版本内容闸**（old.ttf vs new.ttf，ink_ratio/IoU/新增删除单列）+ **精确 glyf 轮廓 diff**；A v1.7.2→v1.7.3 期望 0 changed；
- 输入摘要 sidecar（font/baseline/manifest/script/argv）+ 统一退出码（0 PASS / 2 不可复用 / 3 超阈值 / 1 fail-closed）；
- source-mask 闸只对 **real 层**；合成层单独用分层盲审，不冒充“源墨保真”。
