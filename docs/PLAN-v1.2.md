| 指标 | 真跡 | 霞鹜文楷（恒等） | 当前笔墨滤波 | 目标 |
|---|---|---|---|---|

## 2.0 骨架来源选型（已实测，2026-10-22）

问题：为什么用霞鹜文楷的轮廓，思源宋体/黑体是不是更合适？

**测法**：120 个留出真字，各自按墨迹外框归一化到 96×96/256×256 后取骨架，
比较（a）骨架 Chamfer 距离（越小越接近真字骨架中心线），（b）骨架端点/分叉数（越少越干净）。

| 骨架来源 | Chamfer（96 网格） | 每字端点数 | 每字分叉数 | 骨架像素 |
|---|---|---|---|---|
| **霞鹜文楷（楷）** | **3.76** | **15.6** | **38.8** | 1196 |
| 思源宋体 Light（宋） | 4.53 | 21.7 | 59.8 | 1082 |
| 思源黑体 CN（黑） | 4.72 | 16.8 | 45.9 | 1015 |
| 真字（参考，含木刻噪点） | — | 18.6 | 55.5 | 1030 |

结论：**楷体骨架最接近刻本**（Chamfer 低 17–18%，毛刺少 40%）。
原因：宋体/黑体的笔画末端有顿角、转折是厚接点，骨架化后在这些位置多出短枝；
刻本楷书的笔画是分离的，骨架更干净。

注意两点局限：
1. 真字的字面框当初按 80% 权重对齐过霞鹜文楷，对楷体略有偏向（但两边都做了独立外框归一化，偏差有限）。
2. 早期曾用某系统黑体做过一次代测，数值与思源黑体差异明显（4.46 vs 4.72），**该组数据已作废**；
   上表所有数字均来自 OFL 字体（霞鹜文楷、思源宋体、思源黑体）。

因此：**继续用霞鹜文楷作骨架来源**，但在 M1 增加「毛刺剪枝」与「按字回退」两步；
思源宋体/黑体保留为备选（若日后许可或覆盖出问题可替换）。

## 2. 方案 A（主推）：骨架 + 参数化笔刷

### 2.1 原理

```
霞鹜文楷轮廓 ──512px 栅格──► 骨架图 ──► 笔画图（节点/边）
                                      │
真字 1,675 个 ──► 骨架 + 距离变换 ──► 拟合宽度模型参数
                                      ▼
                              变宽度渲染（圆盘/四边形扫掠）
                                      ▼
                              potrace 矢量化 ──► 合字
```

### 2.2 宽度模型（待拟合）

对骨架上的每个点，取局部方向 θ（竖=90°）与到端点距离 d：

```
r(θ, d) = r0 · (1 + k·|sin θ|^p) · taper(d) · junction(d)
taper(d)  = 0.35 + 0.65 · min(1, d / L_t)
junction  = 1 + g · exp(-(d_j / L_j)^2)      # 靠近交叉点加粗（顿笔）
```

拟合参数：`r0, k, p, L_t, g, L_j`。目标函数：真字掩膜与其骨架重建掩膜之间的
对称差 + 宽度分布 KS 距离。

### 2.3 里程碑（每格约半天）

| 阶段 | 内容 | 验收 |
|---|---|---|
| M1 | 骨架提取 + 笔画图 + 毛刺剪枝（短于 5 px、仅一端连接的枝）；60 字可视化 | 端点数接近真字水平（≈16–20/字）；无断笔；孔洞数与 WenKai 一致 |
| M2 | 宽度模型 + 渲染器 + 参数拟合 | 宽度比进入 1.19±0.08；竖/横中位误差 <8% |
| M3 | 120 留出字评测 + 4 档字号目测 + 失败案例库 | Dice ≥ 0.50；无断笔/粘连 |
| M4 | 全量 19,317 生成 + 重建字体 + A/B 对照 + 打包 v1.2.0 | 13_qa 全绿；发布包可复现 |

### 2.4 硬性约束

- 结构由 WenKai 骨架决定，**不允许出现错字/缺笔**；渲染后做连通域数与孔洞数校验，不一致即回退。
- 许可：骨架来自 OFL 字体，参数来自自有扫描，**全链路干净**。
- 保留 `--method brush` 作为永久回退；新方法不触碰 1,675 个真字。

## 3. 方案 B（对照）：zi2zi-JiT LoRA 全量 + 结构闸门

- 训练：1,675 字、batch 16、20,000 步（MPS 约 1.5–2 h）。
- 生成：19,317 字约 2.8 h（25 步）或 1.2 h（10 步）。
- 闸门：孔洞数一致 + bbox 归一化 IoU > 0.45，不通过回落方案 A。
- 风险：权重许可未明；幻觉率约 25%；与 A 混排可能风格不一致。
- 定位：**只做上限对照**，不默认采用。

## 4. 方案 C（数据）：《史记》独立项目

- 先做页面去卷曲（书脊弯曲曲线拟合 + 逐列重采样），再切字。
- 预期真字 4,000–6,000，真字覆盖率从 8% 提到 25–30%。
- 这是唯一能从根本上改变局面的路线，但周期以周计，**不与本轮混做**。

---

## 5. 建议的执行顺序

1. **先做 A 的 M1+M2（约 1 天）**，用 120 留出字验证是否达到 Dice ≥0.50、宽度比 1.19。
2. 达标 → 直接 M3/M4 出 v1.2.0；不达标 → 记录失败原因，转 B 做上限对照。
3. C 在 v1.2 定版后另开项目。

## 6. 风险与回退

| 风险 | 应对 |
|---|---|
| 骨架有毛刺/断点 | skimage 剪枝 + 端点合并；连通域校验 |
| 拟合退化为"整体加粗" | 同时约束竖/横两个分位数，不只看总墨量 |
| 转折处出现墨团 | junction 增益上限 g ≤ 0.25，并做局部凸包检查 |
| 全量生成时间超预期 | 先跑 2,000 字抽样，确认单字耗时 < 40 ms 再铺全量 |
