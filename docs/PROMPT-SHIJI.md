### 2. 第一优先级：纠偏（这是本任务的核心难点）

**问题**：史记是**双页对开**扫描，中间是书籍线。靠近书脊的几列文字有明显**非刚性变形**
（页面弯曲、列身倾斜、字格变梯形），越靠近中间越严重；页边反而基本正常。

现有的 `scripts/pageproc.py:analyze_page()` 只做**全局旋转纠偏**（`estimate_skew` + `rotate`），
对局部弯曲无效。直接用会在近书脊处切出歪斜、互相粘连的字。

**必须先写一个纠偏步骤**，建议放在流水线最前面（新脚本，例如 `scripts/50_shiji_dewarp.py`），
思路参考：

1. **切分对开页**：在中缝附近找装订线（暗带/亮度低谷），把每页切成左右两半，各自独立处理；
2. **估计弯曲**：文本是竖排，列的**中线**本应是一条直线。逐列提取墨迹质心（或上下基线），
   拟合「列内水平偏移 δ(y)」或整页的平滑位移场；
3. **重映射**：用平滑样条 / 薄板样条（TPS）把位移场反向映射回原页，输出「拉直后」的图；
4. **残差验收**：纠偏后每列中线的**直线拟合残差中位数 < 1.5 px**（100 dpi 下），
   且**近书脊列 / 页边列的残差比 < 1.5×**。两个数都要落盘，不能只靠看图。

**先做 3–5 页样张验证纠偏效果，再跑全量 1672 页**（全量渲染+纠偏很慢，别一上来就跑）。

### 3. 第二优先级：水印与页脚

样例页（第 100 页）底部有水印文字
「Original from and digitized by National University of Singapore Libraries」。
处理方式：先测出水印的灰度/位置特征，能裁掉就裁掉（页脚带），裁不掉就用背景估计抑制——
**但不要用会吃掉笔画的形态学操作**（E17 的教训：腐蚀/膨胀毁过端帽）。

### 4. 流水线复用

纠偏后，四书的流水线可以照搬，只需要换输入与输出路径：

```
scripts/01_segment.py        切字（改 PDF 路径与 work-b/ 输出）
scripts/02_ocr.py            PP-OCR 转录（150 dpi + PP-OCRv6，72 dpi 只有 ~70% 准确率）
scripts/03_build_reference.py 生成参考文本
                             ⚠ 古文正文是公版，但**现代点校本有版权**——只能用公版全文
                             （如维基文库）自行构建，并在 DATA-B 里记录来源
scripts/04_label.py          切片 → 字
scripts/05_select.py         每字选优（默认剔除只出现 1 次的字）
scripts/06_norm.py           字身框归一化
scripts/07_build_real.py     真迹子集字体
scripts/08_make_pairs.py     配对（X=文楷渲染，Y=刻本字形）
scripts/21_train_gan.py      GAN 训练
scripts/10_generate.py       --method gan 生成缺失字（含守卫，回退 --method ribbon）
scripts/36_fill_fallback.py  补齐守卫回退的字
scripts/11_build_full.py     合成完整字体
scripts/13_qa.py             质检
scripts/14_package.py        打包
```

**能照抄的只有超参，数据侧参数必须在新数据上重新拟合。**

| 类别 | 项 | 处理 |
|---|---|---|
| ✅ 照抄 | 网络结构（zi2zi U-Net）、5 层 PatchGAN、hinge loss、数据增强范围、80 轮 | 直接用 |
| ✅ 照抄 | 守卫的**形式**（空输出 / 墨量带 / 连通域差 >3） | 形式照抄 |
| ❌ 必须重拟合 | `ribbon_scale(comp)` 的墨量-复杂度曲线 | 四书是按 1,675 字拟合的（`20.619·comp^-0.330`），史记要重拟合 |
| ❌ 必须重拟合 | `work-b/stroke_rel_width.npy`（逐笔相对宽度分布） | 四书是 45,042 条笔画统计出来的 |
| ❌ 必须重标定 | 守卫的墨量带 `[0.6, 1.5]` | 它是**相对基线字体**的比，换数据后要重测 |
| ❌ 必须重标定 | 推理阈值（四书是 −0.05） | 依赖模型输出分布，重训后要复扫 |

**抄本与刻本的差别要预期到**：四书是**刀刻刻本**，史记是**墨笔抄本**。端帽形态、墨量分布、
笔宽方差的统计结构不同。四书那几组标定结论在抄本上**未必成立**：

- E30（len_ratio 偏短、阈值修不动）
- E34（全字号恒定偏重）
- E35（17% 拆成字集构成 + 字面偏小）

**B 线要在自己的数据上把这三组重做一遍**，而不是继承结论。把四书的数字当预期值直接套，
很可能得出错误判断。

**不要重复走这些已否证的路**：
- 多实例配对（E23/E25）——是拖累；
- 加训到 150 轮（E36）——80 轮后完全持平；
- 拓扑闸门（E24）——会误回退 85% 的字；
- 轮廓层面积补偿（E37）——potrace 不膨胀，没有可补的。

### 5. 评估口径（必须遵守）

- **泛化只认「只出现一次的字」构成的干净集**——这些字从未进入训练。四书那边是 617 字，
  史记需要你自己按同样规则构造（`05_select.py` 的 `cnt[ch]==1`）。
- **B 线的评估参照一律是史记自己的真迹。** 四书的任何资产——617 干净集、`stroke_rel_width.npy`、
  真迹轮廓、守卫阈值——**不得进入 B 线的验收口径**，只能作为并行对照展示。
  理由：两书风格不同域（四书抄写者存疑，史记更确定是姜立纲），拿四书当参照测的是
  "史记模型像不像四书"，分低不能说明模型差，分高反而危险（两个风格域串了）——
  这与 E27 是同一类错误：参照系错了，结论跟着错。
- 结构指标参照**真迹**，不要参照霞鹜文楷（E28：对 A 线是循环论证）。
  用 `scripts/34_struct_score.py`（骨架 chamfer / 端点差 / 交叉点差 / 长度比）。
- 报告必须同时给五项：Dice、墨量比、端帽 cap_mid、端帽 KS、笔内 std。
  **Dice 单独会奖励加粗**，不能只报一个数。
- 结论必须落盘到 `docs/EXPERIMENTS-B.md`，一条实验一节，写清配置、指标、判定、复现命令。
- **干净集的使用制度**（四书这边踩过坑，务必照做）：
  - **干净集不参与拟合，也不参与训练期的逐轮选择**——早停、挑快照用训练内留出的验证集
    （四书是 41 字），那是它的职责；
  - **里程碑级决策**（选发布检查点、定停轮、对比两种配置）用**全量干净集**；
    日常调参用干净集里的**固定抽样**（如固定 150 字），别每次都换一批；
  - 每次用干净集做的决策都要在 EXPERIMENTS-B 里记一笔——同一批字被决策太多次，
    结论会自动变得乐观（四书 E36 的"ep80 还在涨"就是 41 字验证集的波动被当成了趋势）。

### 5.5 一个可选的学术副产品：跨书风格距离

两套字体都建好之后，"史记模型 vs **史记**真迹" 与 "史记模型 vs **四书**真迹" 的 chamfer 之差，
是两书风格距离的第一个量化测度。

**定位是诊断，不是验收**（不参与任何发布判断）：

- 若这个差值**显著大于**书内样本间的地板（四书测得 5.16 px），说明两书风格确实不同域，
  "四书抄写者存疑" 得到数据支持；
- 若接近地板，存疑论减弱。

四书侧已有 `docs/EXPERIMENTS.md` 的真迹互比地板可作基准。做与不做都行，**若做了写进 PLAN-B**。

### 6. 硬性约束（违反会让项目返工）

- **不要执行任何 git 写操作**（add/commit/reset/checkout）——仓库由所有者本人管理。
- **并发上限**：同时最多 **10 线程 / 20 核**。多进程脚本启动前必须
  `torch.set_num_threads(1)`、`cv2.setNumThreads(1)`、
  `OMP_NUM_THREADS=MKL_NUM_THREADS=OPENBLAS_NUM_THREADS=1`，
  worker 数 ≤ 8，**启动后用 `ps` 核对总 CPU ≤ 2000%**。
- **禁止使用任何专有/商业字体**（含系统自带中文字体），即使只做对照或测量。
  只允许 OFL / Apache-2.0 / UFL 等自由许可字体。
- 不要把与 OFL 不兼容的授权数据（商业字库衍生的部件表、笔画表）并入发布字体。
- **训练检查点**（与 AGENTS 同一套规则，所有者 2026-10-25 定）：
  - 训练时**每 10 轮存一个快照**（`--save-every 10`）；
  - 清理时保留 **最终一轮 + 验证最佳一轮 + 核心轮次 50/100/150/200/300/400/500…**；
  - 说明：四书验证过的配方是 **80 轮**（E36 证明加到 150 轮无增益），
    所以当前配方下"核心轮次"只会命中 50 这一档，其余核心点是为将来加长训练预留的；
  - 删完立刻重跑 `scripts/31_ckpt_manifest.py`——这一步单独做已经漏过三次。
- 大文件（PDF、`work-b/`、模型）不入库。

### 7. 建议的推进顺序

1. **纠偏原型**：3–5 页，出纠偏前后对比图 + 列残差指标；
2. **全量切字**：纠偏 → 切分 → 目视抽检 20 页，确认没有切歪/粘连；
3. **OCR 与选优**：得到真迹字表，报告「真迹字数 / 覆盖 CJK 比例」；
4. **真迹字体**：先出 `GuanGeKai-B-Real.ttf`，这是能直接看的第一个成品；
5. **训练**：配对 → GAN 80 轮 → 干净集评估；
6. **全量生成 + 字体级验收**（位置一致性、小字号、守卫回退比例）；
7. **打包发布**。

### 8. 汇报要求

- 每完成一个阶段，给**数字**（不是"效果不错"）：纠偏残差、切字成功率、真迹字数、
  干净集 Dice/chamfer、回退比例；
- 任何"看起来没问题"的判断，都要配一个可复现的度量或对比图；
- 发现与本文档冲突的事实，**以实测为准，并更新文档**。
