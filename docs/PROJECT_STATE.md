## 5. 关键工程决策（以及为什么）

1. **句读圈点是黑色印刷，不是朱笔**。早期按「去红」处理完全无效；改用「厚度 + 连通域」判据：面积 <3000 且距离变换峰值 <2.3 px 的孤立碎片整段剔除（`pageproc.comps` 过滤）。这是 v1.2.0 最重要的修复。
2. **两遍连通域归属**。撇、捺、点常是独立连通域，按质心归格会把它们判给邻字，导致笔画被截断。第二遍把「与本格外框重叠 >45%」的未分配连通域吸回本格，迭代两次。
3. **不再对裁剪图重新二值化**。直接保存「本格所有连通域的联集掩膜」（`work/masks/*.png`），邻字碎片物理上进不来。
4. **字距用全页自相关**（~310 px），每栏再拟合相位与缩放，切分线落在空白带上。
5. **标注以 OCR 为主、标准文本为辅**：OCR 与标准文本一致率 ~89%，不一致时保留 OCR（刻本有异体字，如 爲/為、巳/已）。
6. **字面框归一到基线字体**（80% 权重），保证真字与合成字混排时大小/位置一致。
7. **字体命名避开 LXGW 的 Reserved Font Name**：家族名 `GuanGe Kai`，PS 名 `GuanGeKai-Regular`（OFL 合规要求）。

## 6. 为什么合成字是现在这样（三条路线均已实测）

| 路线 | 结论 | 证据 |
|---|---|---|
| A. 自训 U-Net（像素级风格迁移） | **失败**：二值化 Dice 0.441，恒等基线 0.431，几乎没学到东西 | `EXPERIMENTS.md` E1–E3 |
| B. IDS 部件拼字 | **不可行于全量**：19,317 缺字中仅 1,166（6.0%）能完全用真字拼出；拼出的比例也不好 | `EXPERIMENTS.md` E4 |
| C. 预训练模型 zi2zi-JiT 零样本 | **风格最好**：Dice 0.528 vs 基线 0.309；但结构有幻觉（约 1/4 缺笔/粘连），且权重许可待确认 | `EXPERIMENTS.md` E5–E6 |
| D. 笔墨滤波（当前发布版采用） | 结构 100% 正确，但只是「加粗的楷体」，无笔锋 | `scripts/10_generate.py --method brush` |

**当前发布版用 D**，因为它是唯一能保证 20,992 字结构全对且许可干净的方法。C 是已知的上限方向，但有幻觉与许可两个未决问题。

## 8. 未决问题与建议的下一步（按性价比）

1. **笔刷引擎（推荐）**：用霞鹜文楷骨架（OFL）+ 从 1,675 真字拟合的「方向→笔画宽度/收锋」参数，重渲染 19,317 缺字。结构由骨架保证，许可干净。参考实现思路见 [LingDong-/computer-grass](https://github.com/LingDong-/computer-grass)（但其字形数据是 Arphic PL，**不可复用**）。预估 1–2 天。
2. **zi2zi-JiT LoRA 全量重训**：当前只跑了 5 分钟 / 1,240 步（500 字），指标无提升；用全部 1,675 字跑 1.5–2 小时再评估。需先确认权重许可。
3. **《史记》独立项目**：页面中部卷曲需要展平（书脊弯曲曲线拟合 + 逐列重采样）；预计可把真字从 1,675 提到 4,000–6,000，届时 A/B/C 三条路都会重新变得可行。
4. 结构闸门：若走 zi2zi 路线，必须加「孔洞数一致 + bbox 归一化 IoU」闸门，不通过的回落到笔刷/滤波。

## 12. v1.2.0 变更（2026-10-22）

**唯一改动**：合成字的笔墨滤波从 `dilate(5×1) + erode(1×3)` 改为 **仅 `erode(1×3)`**。

理由（120 留出字实测）：

| 指标 | 真字 | 霞鹜文楷 | v1.1.0 | **v1.2.0** |
|---|---|---|---|---|
| 墨量（相对真字） | 1.00 | 1.20 | 1.26 | **1.09** |
| 竖横比 | 1.17 | 1.08 | 1.50 | **1.18** |

旧参数在一个已经偏重 20% 的基线上继续加粗，导致"又黑又平"。
v1.2.0 只做纵向腐蚀，重量与对比度同时落回刻本区间。

**未变**：真字 1,675、合成 19,317、结构 100% 正确、许可不变。
**仍未解决**：合成字没有刻刀的角状收笔（见 EXPERIMENTS E8）。

## 11. 术语

- **真字 / real**：直接从扫描本矢量化的字形（1,675 个）。
- **合成字 / generated**：用程序或模型生成的缺字（19,317 个）。
- **格 / cell**：版面网格中的一个字位；一个 cell 对应一个连通域簇。
- **槽 / slot**：按字距切出的理论格子，用于定位与缩放。
- **笔墨滤波**：`10_generate.py --method brush` 使用的形态学方案（横加粗竖、竖减细横、闭运算）。
- **闸门 / gate**：对模型输出做结构校验（孔洞数、IoU），不通过则回落。
