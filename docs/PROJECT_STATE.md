## 5. 关键工程决策（以及为什么）

1. **句读圈点原本是红色**，但我们使用的 PDF 已被去色（2026-10-23 实测：全页 `r−g` 最大 9–14，`(r−g)>32` 命中 0 像素），因此按颜色分离无效，改为「厚度 + 连通域」判据：面积 <3000 且距离变换峰值 <2.3 px 的孤立碎片整段剔除（`pageproc.comps`）。这是 v1.1 最重要的修复。若换未去色扫描，`red_mask()` 可直接使用。
2. **两遍连通域归属**。撇、捺、点常是独立连通域，按质心归格会把它们判给邻字，导致笔画被截断。第二遍把「与本格外框重叠 >45%」的未分配连通域吸回本格，迭代两次。
3. **不再对裁剪图重新二值化**。直接保存「本格所有连通域的联集掩膜」（`work/masks/*.png`），邻字碎片物理上进不来。
4. **字距用全页自相关**（~310 px），每栏再拟合相位与缩放，切分线落在空白带上。
5. **标注以 OCR 为主、标准文本为辅**：OCR 与标准文本一致率 ~89%，不一致时保留 OCR（写本有异体字，如 爲/为、巳/已）。
6. **字面框归一到基线字体**（80% 权重），保证真字与合成字混排时大小/位置一致。
7. **字体命名避开 LXGW 的 Reserved Font Name**：家族名 `GuanGe Kai`，PS 名 `GuanGeKai-Regular`（OFL 合规要求）。

## 6. 为什么合成字是现在这样（三条路线均已实测）

| 路线 | 结论 | 证据 |
|---|---|---|
| A. 自训 U-Net（像素级风格迁移） | **失败**：二值化 Dice 0.441，恒等基线 0.431，几乎没学到东西 | `EXPERIMENTS.md` E1–E3 |
| B. IDS 部件拼字 | **不可行于全量**：19,317 缺字中仅 1,166（6.0%）能完全用真字拼出；拼出的比例也不好 | `EXPERIMENTS.md` E4 |
| C. 预训练模型 zi2zi-JiT 零样本 | **风格最好**：Dice 0.528 vs 基线 0.309；但结构有幻觉（约 1/4 缺笔/粘连），且权重许可待确认 | `EXPERIMENTS.md` E5–E6 |
| D. 笔墨滤波（v1.1–v1.2 采用） | 骨架取自文楷、不引入拓扑错误，但只是「加粗的楷体」，无笔锋 | `scripts/10_generate.py --method brush` |
| E. 带状扫掠 + 斜切端头（v1.3.3–v1.3.5 采用，**v1.5.0 起降为回退方案**） | 拓扑与文楷一致 97%，端帽与笔内动态接近真字 | `scripts/10_generate.py --method ribbon` |
| F. GAN（5 层 PatchGAN + hinge + 增强，**v1.5.0 采用**） | 干净集 Dice 0.549、chamfer 5.92 | `scripts/10_generate.py --method gan` |

**当前发布版用 E**（v1.3.3）。D 是 v1.1–v1.2 的旧方案；C 有幻觉与许可两个未决问题（E14 长训练后 Dice 反而降到 0.397）。

## 8. 未决问题与建议的下一步（按性价比，详见 `docs/PLAN-v1.5.md`）

**合成字整体偏重约 17%（E34，全字号恒定）**：12–96px 三种口径一致——
① 同字掉墨率两组相同（12px 0.016 vs 0.015，说明缩小不掉队）；
② 跨组中位数之比 1.16–1.20；
③ 相对文楷真迹 0.75–0.87、合成 0.83–0.94。
**这不是小字号效应**，是固有墨量差；v1.5.0 曾误报为「12–16px 偏重、16px 起持平」，
原因是统计口径错误（两组独立样本的比值数组逐元素相除）。下一版可做一次全局标定。

0b. **加训无效（E36）**：M2 配方从 80 轮拉到 150 轮，干净集完全持平
   （Dice 0.543–0.548 vs 0.549，chamfer 5.87–5.94 vs 5.92）。ep60 见顶后进入平台。
   **「欠训」假设作废**；模型侧提升只能换数据、加容量或提分辨率。

0. **B 线（GAN）重新打开**（E23–E29）：最优配置是单实例 + PatchGAN + 15 轮。
   干净集（617 字，从未训练）上：Dice **0.540 vs ribbon 0.413**、骨架 chamfer **6.68 vs 8.76**、
   交叉点差 **9 vs 13**、崩坏率（Dice<0.30）**0.7% vs 5.7%**。
   **E27 曾以"与文楷拓扑 23/150"否决 GAN，那把尺子对 A 线循环、对真迹无区分度（E28），结论作废。**
   下一步：全量生成 + 字体级验收（`13_qa`、小字号、与 1,675 真迹混排）。
0b. **结构指标口径已修正，但结构本身仍是缺口**（E28）：旧口径「与文楷拓扑全等」作废
   （vs 真迹时 ribbon/GAN/文楷全是 ~11%）。维度化实测：布局级（重心、宽高比）文楷与写本差 1–2%，
   可接受；**笔画级差异明显**——横画角 KS 0.513、字碗数只有 39/120 对得上。
   横画倾角校准已试并证伪（Dice 无收益），原因是 256px 的倾角估计不稳、且绕笔画重心旋转破坏接续。
   **在做出可靠的结构度量之前，不要基于这类人口统计量做形变干预。**
1. **转折（横折方角）**：带状扫掠目前把转折渲染成圆角，这是与写本最明显的剩余差异。

3. ~~笔刷引擎~~ 已完成（E15，v1.3.2 起，v1.3.3 改进）。
4. ~~zi2zi LoRA 全量重训~~ **已证伪**：E14 用 600 epoch / 18,600 步训练，Dice 从 0.441 降到 0.397。
5. **zi2zi-GAN（E16）**：训练已完成（150 epoch）。三类基准（`26_bench.py`）：

## 11. 术语

- **真字 / real**：直接从扫描本矢量化的字形（1,675 个）。
- **合成字 / generated**：用程序或模型生成的缺字（19,317 个）。
- **格 / cell**：版面网格中的一个字位；一个 cell 对应一个连通域簇。
- **槽 / slot**：按字距切出的理论格子，用于定位与缩放。
- **笔墨滤波**：`10_generate.py --method brush` 使用的形态学方案（横加粗竖、竖减细横、闭运算），v1.1–v1.2 使用。
- **带状扫掠**：`render_ribbon`，沿骨架生成带斜切端头的闭合带状多边形，v1.3.2 起使用。
- **闸门 / gate**：对模型输出做结构校验（孔洞数、IoU），不通过则回落。
