# 术语表（唯一规范源）

> **本文件是三线（A/B/C）唯一的术语与命名规范。** 迁移计划与自我更正见 `docs/CONVENTIONS.md`，
> 历史勘误见 `docs/ERRATA.md`。修改词表只改本文件。
>
> 生效日期：2026-10-28。任何文档、代码注释、字体元数据与本文件冲突即为缺陷，
> 由 `scripts/97_check_terms.py` 检查。

## 1. 三条字形线

| 线 | 家族名 | 语料 | 定位（按**书写者与场合**，不按载体） |
|---|---|---|---|
| **A 线** | `GuanGe Kai` | 《四书白文》十八卷 | **名家精写本**——旧传姜立纲（存疑），个人风格最纯，最接近台阁体的「标准手」 |
| **B 线** | `GuanGe Kai B` | 《史记》二十四册 | **旧抄本**——旧传姜立纲，抄手水平参差，笔画更率 |
| **C 线** | `GuanGe Kai C` | 《永乐大典》美国藏本 41 册 | **嘉靖内府录副本**——多人分抄，同字多形，最「官」也最杂 |

三条线**都是写本**（手书墨迹）。差异在书写者与场合，**不在刻还是写**。

## 2. 技术路线

| 规范写法 | 短码（仅表格内；首次出现写全） | 含义 | 状态 |
|---|---|---|---|
| `ribbon` | `RT1` | 带状扫掠 | **降级为回退兜底**：A 线 799 字（4.1%）、B 线 591 字、C 线 1,228 字（7.8%）仍在用 |
| `zi2zi-GAN` | `RT2` | PatchGAN 生成 | 三线主线 |
| `zi2zi-JiT` | `RT3` | 自训练权重 | 未启动 |

**R0 / R0b / R1–R7 保留给闸门判据**（`scripts/30_gate_rules.py`、`docs/EXPERIMENTS.md` 的 E24 表），
技术路线**不得**用 R + 数字。

代码里的写法是 `--method gan` / `--method ribbon` / `patchgan`，文档与代码对齐。

## 3. 版本号与文件名

- **版本号本身只写 `vX.Y.Z`**（如 `v1.2.1`）；禁止把线字母写进版本号内部（禁 `v1.2.1-B`）。
- **文件名允许带线名**：`GuanGeKai-B-v1.2.1.zip`、`RELEASE-v1.2.1-B.md` 合法，其中 `B` 是线名。

## 4. 载体用语（《四书白文》是写本）

| 正确 | 禁止 |
|---|---|
| 写本 / 明写本 / 明代精写本 | ~~刻本~~ / ~~明刻本~~ / ~~馆阁体刻本~~ |
| 写本真迹 / 真迹 | ~~刻本真迹~~ |
| 墨笔笔锋 | ~~刻刀笔锋~~ / ~~刀刻痕迹~~ |
| 书写连笔 / 磨损 | ~~原书印刷断笔~~ |
| 墨笔写本（B/C 对 A 的描述） | ~~刀刻刻本~~ |
| 名家写本 / 旧抄本 / 内府录副本 | ~~刻本 / 抄本 / 类书~~（三线差别的旧说法） |

**合法例外**：提到《史记》通行本、宋元刻本、字典刻本等**他书或出版类型**时，「刻本」照常使用，
在该行尾加 `<!-- term-ok -->` 即可（检查器认这个标记）。

## 5. 字体名与书体名

- 字体名固定为 `GuanGe Kai` / `GuanGe Kai B` / `GuanGe Kai C`，不改。
- 书体：明代文献多称**台阁体**，清代多称**馆阁体**。本项目以**馆阁体**作通称，
  引用明代语境时保留「台阁体」原词。

## 6. 路径约定

`work/`、`release/`、`data/release-a.json` 对 **A 线无后缀**；B/C 线用 `-b`/`-c`。
这是历史遗留，**保留现状**：看到无后缀路径即 A 线。

## 7. 引用规范

- 引用书格著录（王世贞跋等）时写「据书格著录」，不得写成「本件卷末有跋」。
- 本地文件名 `四书白文.18卷.旧传明.姜立纲.pdf` 与书格原站名（含「明钞本」）不同，引用时分开写。
