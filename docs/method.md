# 技術路線 / Method

## 1. 從掃描到單字

* **渲染與糾偏**：PDF 每頁是一張 ~6700×6000 的 JPEG（約 300 dpi）。用投影/Hough 估頁面傾角，旋轉 0.1–0.4°。
* **去除紅圈點**：刻本上的句讀是後人硃筆圈點。以 `R − (G+B)/2` 偵測紅像素，只在紅色連通域附近
  做 inpaint，避免像「直接減紅通道」那樣在筆畫交疊處挖洞。
* **去除版框**：長核形態學開運算取橫/豎框線，膨脹後從墨跡中減去；再過濾細長連通域。
* **文字塊與欄**：以 121×121 均值濾波得到墨跡密度，取密度 > 22% 峰值區域為文字塊；
  以「每列有墨的行數佔比 > 5%」作為欄的判據（欄間走廊近乎全白）。
* **字距與字元分割**：對整頁各欄的歸一化縱向投影做自相關，得到字距（約 310 px）；
  每欄在此基礎上擬合相位與縮放，使切分線落在空白帶上。再用**連通域質心最近格**分配，
  保證同一字的偏旁不會被切到鄰格。

## 2. 標註

* **逐頁 OCR**：RapidOCR（PP-OCRv6）在 150 dpi 上偵測直欄，整欄辨識，實測準確率 ~99%。
* **標準文本對齊**：以《四書》標準白文（大學/中庸/論語/孟子，OpenCC 轉繁）為詞典，
  對每頁做 `difflib` 局部對齊，得到「第 n 個切片 ↔ 第 m 個標準字」的映射。
* **以 OCR 為主、文本為輔**：OCR 與標準文本一致率約 90%；不一致時仍以 OCR 為標籤
  （刻本保留異體字，如 爲/為、巳/已、云/雲），文本只用於頁序與位置校驗。

## 3. 每字最優樣本

同一字常有數十至上千個樣本。作法是：

1. 每個切片正規化為 48×48（按墨跡外框、等比）。
2. 以「均值 → 丟棄最差 25% → 重算均值」迭代 3 次，得到穩健中心。
3. 綜合評分 = 到中心的距離 − 0.25·銳度 − 0.15·方正度 + 0.35·字面尺寸離群 + 0.15·紅色殘留。
4. 取評分最低者。少數僅有 1 個樣本的字直接採用。

## 4. 向量化與字身框

* 二值化（Otsu，限制在 120–200）→ 去斑 → potrace（`turdsize=8, alphamax=1, opticurve`）。
* 每個字按其**格心**映射到 em：字距 310 px ↔ 880 units（UPM 1000，基線 0，字面 0–880）。
* 為使真實字形與生成字形混排一致，再把每個字的外框按 80% 權重向基線字體（霞鶩文楷）
  的同字外框對齊（等比縮放 + 平移），保留 20% 刻本的原始大小差異。
* TrueType 方向：外輪廓順時針、內洞逆時針；三次曲線用 cu2qu 轉二次（誤差 ≤ 1 unit）。

## 5. 缺失字的生成

> 說明：曾以 U-Net 在 2,300 組「霞鶩文楷 → 刻本字形」配對上做風格遷移（MPS，45 epoch，
> val L1 0.21）。模型能重建結構，但筆畫末端出現明顯「鬼影」，質檢未達出貨標準，
> 因此發布版改用下方**程序化筆墨濾波**；訓練與推理代碼仍保留在
> `scripts/09_train.py` / `scripts/10_generate.py --method model`，供後續改進。

### 發布版採用的方法

* **配對**：對 1,686 個真實字，用同一套 em 映射把霞鶩文楷渲染成 256×256，與刻本切片配對。
* **模型**：4 層 U-Net（32→512），輸入基線字形、輸出館閣體字形；損失 = BCE + 0.5·L1 + 2·邊緣梯度差。
* **訓練**：M3 Ultra / MPS，batch 16，80 epoch，約 25 分鐘；隨機仿射（±3°、±5%、±5 px）增強。
* **程序化筆墨濾波**：對缺失字，取霞鶩文楷 256×256 點陣 → 橫向膨脹（豎畫加粗）→ 縱向腐蝕
  （橫畫減細）→ 3×3 閉運算 → 輕微高斯；再以與基線的 IoU 做結構守門，最後 potrace 向量化、
  按 100% 權重對齊基線外框。效果是「豎粗橫細、血肉加重」，接近館閣體的視覺重量。

## 6. 已知偏差

* 刻本用字只有 2,300 個，且多為高頻字；生成字在筆鋒、起收上與真實字有可感知差距。
* 風格遷移模型是「局部筆墨濾波器」，不理解筆順；極少數複雜字可能出現筆畫粘連。
* 未做 hinting；小字號渲染依賴系統 autohinter。
