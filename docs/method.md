# 技術路線 / Method

## 1. 從掃描到單字

* **渲染與糾偏**：PDF 每頁是一張 ~6700×6000 的 JPEG（約 300 dpi）。用投影/Hough 估頁面傾角，旋轉 0.1–0.4°。
* **去除句讀圈點**：原書圈點是**紅色**的，但本項目使用的 PDF 已去色（實測無紅色像素），
  故不能用顏色分離：以「厚度 + 連通域」判據剔除，細於 2.3 px 的孤立碎片（圈點弧線、紙褶）
  在分配前整段處理。
* **去除版框**：長核形態學開運算取橫/豎框線，膨脹後從墨跡中減去；再過濾細長連通域。
* **文字塊與欄**：以 121×121 均值濾波得到墨跡密度，取密度 > 22% 峰值區域為文字塊；
  以「每列有墨的行數佔比 > 5%」作為欄的判據（欄間走廊近乎全白）。
* **字距與字元分割**：對整頁各欄的歸一化縱向投影做自相關，得到字距（約 310 px）；
  每欄在此基礎上擬合相位與縮放，使切分線落在空白帶上。
* **字元歸屬（兩遍）**：先按連通域質心歸格；再把「與該格外框重疊 >45%」的未分配連通域
  （被切開的撇、捺、點）吸回本格，迭代兩次。最後以本格所有連通域的聯集作為字形掩膜，
  **不再對裁剪圖重新二值化**——鄰字碎片因此無法混入。

## 2. 標註

* **逐頁 OCR**：RapidOCR（PP-OCRv6）在 150 dpi 上偵測直欄、整欄辨識；乾淨頁面的逐欄辨識約 99%，
  但與《四書》標準白文的**字面一致率為 87.1%**（5 萬餘行中有一致結果者），差異多為異體字
  （爲/為、巳/已、云/雲），並非辨識錯誤。兩個數字口徑不同，勿混用。
* **標準文本對齊**：以《四書》標準白文（大學/中庸/論語/孟子，OpenCC 轉繁）為詞典，
  對每頁做 `difflib` 局部對齊，得到「第 n 個切片 ↔ 第 m 個標準字」的映射。
* **以 OCR 為主、文本為輔**：OCR 與標準文本一致率約 90%；不一致時仍以 OCR 為標籤
  （刻本保留異體字，如 爲/為、巳/已、云/雲），文本只用於頁序與位置校驗。

## 3. 每字最優樣本

同一字常有數十至上千個樣本。作法是：

1. 每個切片正規化為 48×48（按墨跡外框、等比）。
2. 以「均值 → 丟棄最差 25% → 重算均值」迭代 3 次，得到穩健中心。
3. 綜合評分 = 到中心的距離 − 0.25·銳度 − 0.15·方正度 + 0.35·字面尺寸離群 + 0.15·紅色殘留。
4. 取評分最低者。**僅出現 1 次、無法做同字聚類校驗的字一律不用**（實測這類字確有錯標），
   因此 2,292 個字標籤中只保留 1,675 個進入字體。

## 4. 向量化與字身框

* 二值化（Otsu，限制在 120–200）→ 去斑 → potrace（`turdsize=8, alphamax=1, opticurve`）。
* 每個字按其**格心**映射到 em：字距 310 px ↔ 880 units（UPM 1000，基線 0，字面 0–880）。
* 為使真實字形與生成字形混排一致，再把每個字的外框按 80% 權重向基線字體（霞鶩文楷）
  的同字外框對齊（等比縮放 + 平移），保留 20% 刻本的原始大小差異。
* TrueType 方向：外輪廓順時針、內洞逆時針；三次曲線用 cu2qu 轉二次（誤差 ≤ 1 unit）。

## 5. 缺失字的生成

發布版（v1.3.2）採用**帶狀掃掠渲染**，結構由骨架保證、筆形由程序化生成。

### 5.1 發布版：帶狀掃掠（v1.3.2）

對每個缺失字：

1. 用霞鶩文楷（OFL）渲染 256×256 點陣，提取骨架與每點半寬；
2. 每條筆畫從真字的「逐筆相對寬度」分佈抽樣一個墨量係數（`dip`，先冪次再歸一，保證均值 1.0）；
3. 沿骨架掃掠**帶狀多邊形**：左右偏移線的終點錯開 → **斜切端頭**（不再是圓頭）；
4. 疊加沿程 `taper`（起筆略重、收筆略輕）；
5. 與基線字形做 IoU 守門（<0.7 回退），potrace 向量化，按 100% 權重對齊基線字身框。

> 為什麼不是形態學濾波：濾波只能整體加粗/減細，做不出端頭形狀；
> 而**圓頭是「圓盤點印」的產物**，換成帶狀掃掠後端頭自然成切角。
> 實測（91 字無洩漏集）：墨量 1.077、端帽 KS 0.101、逐筆 std 0.229（真跡 1.000 / — / 0.248）。

效果：「豎粗橫細、血肉加重」，視覺重量接近刻本；但**沒有刻刀筆鋒**，本質上是加粗的楷體。
這一點在 [PROJECT_STATE.md](PROJECT_STATE.md) §2 已明確標注。

## 6. 已知偏差

* 刻本用字只有 2,292 個標籤（保留 1,675），且多為高頻字；生成字在筆鋒、起收上與真實字有可感知差距。
* 帶狀掃掠不理解筆順與轉折，橫折仍是圓角；這是當前最大缺陷。
* 未做 hinting；小字號渲染依賴系統 autohinter。
