## 已知限制

- **孔洞不再作为工程目标**：完全丢孔 1.9%、偏少 29.0%。两项探针（B/E9）表明加闭运算核
  （4→8→12）会让「孔数一致」从 52.3% 掉到 34.4%（大核把笔画粘连处闭成假孔），残差的孔
  内部是纸面灰度（196–213）而接缝是墨（p25 74–91）——**是抄本断笔与细接缝，不是分辨率**。
  与 A 线 E38（600 dpi 只恢复 22%）结论一致：接受现状、如实披露。根治只能换更好的扫描件。
- **训练集仍是 4,070 对**，本版真迹 4,078 中有 8 字未参与训练（占 0.2%，收益在噪声内，未为此重训）。
- **崩坏率 3.2%**（Dice < 0.30），高于 A 线 0.7%。
- chamfer 5.60 相对真迹地板 3.57 差 57%（A 线是 15%）——原生 150 dpi 是主要天花板。
- 十篇「表」（卷十三–二十二）在参考文本里是表格结构，该 12 页不进入真迹字表。
- 未做 hinting；小字号依赖系统自动微调。
