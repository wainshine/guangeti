# GuanGe Kai v1.7.1（A 四书）

> **补上标点、数字与空格。** v1.7.0 只更正了身份（刻本 → 写本），字集仍只有 CJK 基本区，
> 直接排版会满篇 □。本版把最小可用集合补齐。

## 本版变更

| 项 | 内容 |
|---|---|
| **字集扩充** | `20,992 → 21,034`：新增 **44 码位**——空格（U+0020 / U+3000）、半角数字 0–9、全角数字 ０–９、中文标点 20 个（`、。，；：？！「」『』（）《》〈〉—…·""''`） |
| **来源** | 字形取自霞鹜文楷（OFL 1.1，未使用其保留字体名），upm 同为 1000，**1:1 复制不缩放** |
| **不改** | 基本区 20,992 字一字未动；真迹 1,675 / GAN 18,518 / 回退 799（4.1%）不变 |
| **拉丁不补** | A–Z 仍由系统回退。文楷的拉丁是现代印刷体，与楷书笔意冲突，塞进去比回退更难看 |
