### M4 前置探针（2026-10-28 实测，**先看这个再决定是否训练**）

在烧 12–16 小时之前先量「256 丢了多少细节」，复用 `pairs_single.npz` 的 120 个字：
文楷 512 渲染作为真值 → 降到 256 → 升回 512 → 与真值比。

```
512 与 256 往返 IoU        中位 0.966
细笔画（5×5 腐蚀带）丢失    中位 14.0%   P90 16.3%
```

**判读**：面积只丢 3.4%，丢的主要是**描边带**（撇尖、钩、转折外缘），结构本身没塌。
按「<10% 可省、>30% 值得」的预设，14% 落在灰区——**分辨率是次要瓶颈，不是主因**。

**若要执行 M4，必须先补齐四处，否则跑完看不出结果**：

1. **训练三处联动**：pairs 目标 256→512、文楷输入 256→512、落盘描摹 512（v1.3.5 已有）；
2. **评估也要 512**：`65_eval_b.py:38`、`32_eval_clean.py:27`、`34_struct_score.py:34`
   现在都是 `S = 256`，512 训出来再缩回 256 算指标，**想买的细节在指标里不存在**；
3. **必须有同预算对照臂**：`20 轮 @256` vs `20 轮 @512`，否则 5.98 分不清是「没用」还是「没训够」；
4. **先试一轮量成本**：512 下 batch 16 可能放不下，需降到 8/4，80 轮实际是 **14–16 小时**而不是 11–13。

**归属**：M4 属 A 线；A 通过判据后 B/C 再跟，否则是 36 小时机器时间。

### M0.2 推理阈值扫描

GAN 输出经 tanh，判 ink 的阈值现在是 `>0`。扫描阈值 −0.15…+0.05，**步长 0.025**（连续量，成本可忽略）：

| 阈值 | Dice | len_ratio | chamfer |
|---|---|---|---|
| −0.15 | ? | ? | ? |
| −0.10 | ? | ? | ? |
| 0（现状） | 0.540 | 0.84 | 6.68 |
| +0.05 | ? | ? | ? |

**通过标准**（三条都是硬条件）：

| 判据 | 阈值 |
|---|---|
| len_ratio | 落入 0.95–1.05 |
| Dice | 相对基线下降 ≤0.01 |
| **端帽 KS** | **不劣于基线 +0.02**（E17 的教训：等墨量操作曾毁端帽） |

> 这不是 E17 的形态学膨胀（那个毁端帽）。改阈值只移动判定边界，输出本身不变形。
>
> **失败分支**：若扫不出同时满足三条的阈值，说明 len_ratio 0.84 的成因不是"判定偏保守"，
> 而是"收笔过尖/骨架端部缩短"——这种情形下正确结论是
> **「len_ratio 不能用阈值修，留待 M2 从模型侧解决」**，不要卡在 M0。

## M1 — 目标图去模糊（50 分钟，最便宜的上游归因）

### 问题

`08_make_pairs.py` 的目标链是：真迹**硬二值掩膜** → 仿射 → `GaussianBlur(σ=1.0)`。
对本来就干净的二值图做模糊没有任何去噪收益，只有信息损失：256px 下笔画半宽约 5px，
σ=1.0 把 1px 的方角糊成 2–3px 圆角。

**"转折还是圆的"有可能一部分是模型忠实复现了圆角目标。**

### 实验

1. 以 σ=0.5 重建训练集 `work/pairs/pairs_blur05.npz`（σ=1.0 版本改名 `pairs_blur10.npz` 保留）；
2. **评估集不动**——`work/pairs_single.npz` 本来就没做高斯模糊（只有仿射插值，
   中间灰度 2.74% vs 训练集 9.06%）。原计划里"评估集也 σ=1.0"的假设是错的：
   实际是**训练目标比评估参照更糊**，这一侧的修正恰好让两者靠拢；
3. 同配置（单实例 + 当前 4 层 PatchGAN）训 15 轮，每 5 轮存快照；
4. 与基线（0.543 / chamfer 6.68 / len_ratio 0.84）对比。

**通过标准**（按优先级）：

| 判据 | 阈值 |
|---|---|
| 骨架 chamfer | 不劣于 6.68，且至少一项结构指标改善 |
| Dice | 允许 −0.02（锐边对钝参照天然少重合） |
| 端帽 KS | **参考项**，不作通过条件（KS 对锐度敏感） |
| 视觉面板 | 20 个未见字的 文楷/GAN/真迹 三行图，人工确认方角是否出现 |

若四项都无改善，说明圆角来自模型容量而非目标，M1 归档并回到 σ=1.0。

## M2 — 判别器与正则（4–5 小时，一次 run 两处升级）

M1 通过后才做。三处改动同时上，但**用快照曲线保留归因能力**：

| 改动 | 理由 | 归因方式 |
|---|---|---|
| PatchGAN 4 层 → **5 层（≈70×70）** | 补齐 pix2pix 原版感受野；现注释已承认 46px | 同轮数（ep15）与基线直接比 |
| BCE → **hinge loss** | 缓解判别器过强导致的梯度饱和 | 同上 |
| **数据增强**（±2° 旋转、±3px 平移、0.95–1.05 缩放，X/Y 同步） | 项目至今零增强；E26 曲线显示 15 轮即过拟合 | 看能否训到 40 轮以上不回落 |

- 训练 80 轮，**每 5 轮存快照**，每 5 轮跑一次 `32_eval_clean` + `34_struct_score`，出曲线；
- **检查点选择规则**：按**干净集**的 Dice + chamfer 曲线选，**不用训练内 valDice**
  （val 只有 41 字，样本太小）；
- **验收**：干净集 Dice 曲线在 ep40 前不回落，且 ep40–80 段能维持峰值。

> **归因要打折**：加增强后 ep15 与基线不再严格可比（增强改变早期动态），
> "同轮数直接比"只给方向。要定量归因判别器，需再加一个"仅增强、不换判别器"的 15 轮对照
> （+50 分钟，可选）。

**若曲线仍是 ep15 见顶后下滑**，按下面顺序排查，**不要直接跳 M4**：

1. **先加 lr 线性衰减 + EMA**（约 +1 小时）。计划只做了几何增强，增强不足时 ep15 见顶
   仍然可能是过拟合，此时跳 512 是用最贵的方案修未必是它的问题；
2. **训练集内锐度抽查**（5 分钟）：挑 20 个**训练过**的字，看 G(x) 有没有方角。
   - 训练集内有方角、干净集没有 → 泛化/数据瓶颈，M4（512）有道理；
   - 训练集内也糊 → 容量或目标问题，**M4 无用**，应回头查目标链与模型容量；
3. 两项都排除后，才进 M4。

## M3 — 全量生成与字体级验收（约 2 小时）

用 M1/M2 的胜出检查点生成 19,317 字。

**先做两件事**：

1. **重扫推理阈值**——M0 的最优阈值是针对 ep15 旧模型的，换模型后不再最优（几分钟）；
2. **新写一个生成方法**（建议 `--method gan`）：**不要复用 `--method gan_gated`**，
   那是 E24 证伪的旧闸门（填噪点洞 + 字碗数 vs 文楷全等，实测回退 85%），
   直接跑会得到一个几乎全 ribbon 的字体。新守卫是另一套逻辑：
   空输出 / 墨量越界 [0.6,1.5] / 连通域差 >3 → 回退 ribbon。
   回退清单要落盘（`work/gan_fallback.json`），并对回退字与 GAN 字的**接缝**做 5% 抽样视觉检查。

**必须新增两项验收**（此前 A 线没有）：

1. **字面位置一致性**：GAN 的 Dice 从 0.543（未对齐）涨到 0.591（质心对齐后），
   说明输出有系统性平移偏差。虽然 `normalize_to_base` 会修一部分，
   仍要统计 1,675 真迹与 19,317 合成字的**字面框中心分布**，偏差中位须 < 1% em；
2. **小字号混排**：12/14/16px 下真迹与合成字的墨量比（A 线是 0.76 vs 0.89，
   GAN 偏瘦可能反而拉近——需实测，不能假设）。

**廉价守卫**（不是 E24 的闸门复活）：空输出 / 墨量越界 [0.6,1.5] / 连通域差 >3 → 回退 ribbon。
C 类实测触发率 3.3%，预期全量 <5%。

## 决策点

| 里程碑 | 通过则 | 不通过则 |
|---|---|---|
| M0 | 进入 M1 | 先解决墨量偏差，否则字体级必然重跑 |
| M1 | 进入 M2 | 归档，目标回 σ=1.0，直接 M2 |
| M2 | 进入 M3（GAN 作 v1.4.0 主体） | 若仍早熟 → M4；若只是略降 → 用 M2 最好的快照进 M3 |
| M3 | 发 **v1.5.0**（GAN + 新守卫） | 退回 ribbon，B 线存档 |

## 时间预算

M0 0.5h + M1 1h + M2 **5–6h**（增强在 `num_workers=0` 的主进程做，每轮会超过 153s）
+ M3 2h ≈ **9–10 小时**。

**不是完全无人值守**：M1 的视觉面板、M3 的小字号混排都需要人工目测；
M2 的失败分支还需要人决定是否加 lr 衰减/EMA。M4 另计。
