## 2. 问题定义与范围

刻本与合成字的几何差异有两类，本方案**只做这两类**：

| 特征 | 刻本 | 当前 | 指标 |
|---|---|---|---|
| **收笔**（横/竖的顿、钩的踢） | 斜切或方切，尖端有角 | potrace 圆弧头 | 尖端夹角、不对称度 |
| **转角**（横折） | 方折 + 顿角 | 圆角 | 转角曲率半径 |

**明确不做**（范围边界，非遗漏）：

- **捺脚**（捺末端的膨大足）：形状是「膨大 + 弧底」，不是切角，需要重排整段轮廓，v1.3 不做；
- **起笔顿头**：属于自由端点，由同一套端帽机制覆盖（不单独建模）；
- **撇/捺的锋尖**：本就是渐细，**不加角**（分类器负责排除）；
- **笔画内部的宽度剖面**：v1.2.1 的墨量/对比度已达标，不在本版改。

## 3. 为什么是矢量

合成字是矢量轮廓（`work/generated.jsonl`，em 空间）。圆头有两个来源：**霞鹜文楷本身的圆终端设计** + **potrace 的二次圆化**——两者都可以在轮廓上直接改写。

| | 栅格贴模板（E10） | 矢量改写 |
|---|---|---|
| 尺寸匹配 | 需按笔宽缩放，误差累积 | 以笔宽为单位，无缩放 |
| 旋转对齐 | 需估切线，有系统偏差 | 用端点精确法向 |
| 接缝 | 贴片与笔画间有重叠/缺口 | 轮廓连续 |
| 转角 | 做不了 | 可一并处理 |

> 修正上一版的措辞：E8 证明的是**各向同性圆盘/条带**产生不了角状收笔；`render_polygon` 能产生平头但产生不了斜切+角。
> 本方案不否决栅格路线“原理上可行”，只主张**矢量在误差源上更少**。

## 4. 方法

### 4.1 工作空间：em 轮廓，不重渲染

直接读 `work/generated.jsonl` 的 em 空间轮廓；端点、切线、半宽在 em 空间重算
（栅格 256 ↔ em 1000 的映射是确定的，`glyphvec.to_em` 已有）。

**不重跑** 10_generate、不重跑 potrace、不重做滤波——v1.2.1 的墨量/对比度成果原样保留。

### 4.2 收笔：交点定界 + 拟合贝塞尔端帽

**不再用「3 条直线段」**（首轮审查指出：三线段只是机械倒角，不是顿笔）。改为：

1. **定界**：过端点 `P`、以 `d` 为法向作直线 `L`；取轮廓与 `L` 的两个交点 `A`、`B`（保证 C0 连续），
   `A–B` 之间的轮廓段即端帽区。**不再用 `(Q−P)·d>0` 这种半平面判据**（会产生台阶）。
2. **替换**：把 `A–B` 段换成一条三次贝塞尔：起点 `A`，终点 `B`，控制点
   `C1 = A + α·w·d + β·w·n`，`C2 = B + γ·w·d + δ·w·n`，尖点由曲线自然形成。
3. **参数拟合**：对真字的每个端帽，用同样的交点定界取 `A,B`，再拟合 `(α,β,γ,δ)`；
   取分箱中位数。这样端帽形状**来自真字实测**，不是人造图元。

### 4.3 转角（可选，M4 消融决定）

对骨架转角 > 40° 的节点：取两侧外侧轮廓拟合直线，求交得斜接；斜接长度 > 2.5w 退化为 bevel。
**M4 做消融**（仅端帽 vs 端帽+转角），KS 改善 < 0.05 则砍掉。

### 4.4 分箱：8（类型）× 2（主/次）

| 维度 | 取值 | 说明 |
|---|---|---|
| 类型 | 横 / 竖 / 撇 / 捺 / 点 / 提 / 钩 / 折 | 8 |
| 主次 | 该字内笔画长度排名前 1/3 为主笔 | 改用**排序**而非「≥0.55 字宽」（窄字失真） |

样本：**17.2 个自由端点/字 × 1,675 = 28,810**（实测，见下），16 格平均 ~1,800。
`64 格（再分 4 方向）` 作为 M3 的 ablation：8×2 与 8×2×4 的 KS 差 < 0.02 则用 8×2。

> 端点数复算：50 字 → 867（17.3/字），200 字 → 3,447（17.2/字），×1,675 ≈ 28,810。
> E10 的 3,447 是 **200 字**的样本量。

每格 < 40 时按「类型」→「全局」两级回落。

### 4.5 自交校验与回滚

每次端帽/转角替换后，用 `shapely` 检查自交面积；> 0.01w² 即回滚该端点。
**校验函数在 M1 先写好并单测**，不留到 M2。

## 6. 指标定义与稳定性（M1 必须先做）

**尖端夹角**：端点处取端帽区轮廓，拟合两条直线，夹角。
**不对称度**：端帽区质心在法向 `n` 上的投影 / `w`。
**转角曲率半径**：转角处外侧轮廓拟合圆弧的半径 / `w`。

**稳定性前置**：把 1,475 个拟合字随机二分，各算一次分布，得组间 KS。验收阈值必须 > 该组间 KS，
否则指标本身噪声就超过信号。这是第 6/7 项阈值唯一的合法来源。
