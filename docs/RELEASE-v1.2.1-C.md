## 2. 模型

- 训练集：`work-c/pairs/pairs.npz`（v3d2，5,002 对）；从零训练 **90 轮**；
- 检查点：`work-c/ckpt/v1.2.1/c_ep090.pt`；
- 配置：`hinge + patchgan + aug`，`lr 2e-4`，每轮保存；
- 生成工作点：`thr +0.30 / close 1 / blend 0.8 / --struct-guard / ink-gain 1.25`。
