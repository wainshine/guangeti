# GuanGe Kai v1.3.5

> 渲染与矢量化分辨率提到 512，并把轮廓简化为多边形：**字体从 23.3 MB 降到 14.9 MB**，
> 合成字的轮廓墨量与真迹基本相等（+6.9% → −0.5%）。

**Version 1.3.5** — 20,992 字全覆蓋：1,675 真迹 + 19,317 合成（88.3% 经 ribbon 风格化）。

## 改了什么

### 1. 512 渲染 + 512 矢量化

`--res 512`。potrace 的半像素外扩在 256 下相当于 3.9 字体单位，在 512 下只有 1.95；
实测轮廓墨量税从 **+6.2% 降到 0.0%**。

### 2. 轮廓简化

`--simplify 2.0`（即 2/1000 em）：把曲线采样成折线后做 Douglas-Peucker 简化。
节点数降约 30%，肉眼无差别（12–512px 逐级比对过）。

### 3. 单阶段 worker

渲染→守卫→矢量化一气呵成，不再写 1.2 GB 的 `gen_masks.npy`，也不再有 5 GB 的 512 掩膜数组。

## 指标

| 项 | v1.3.4 | v1.3.5 |
|---|---|---|
| 字体大小 | 23.3 MB | **14.9 MB** |
| 经 ribbon 风格化 | 90.0% | 88.3% |
| 轮廓墨量（合成/真迹，严格填充口径） | 1.146 / 1.072 = **+6.9%** | 1.067 / 1.072 = **−0.5%** |
| 实际渲染墨量（合成/真迹） | 1.009 / 1.009 | 1.009 / 1.009 |
| 掩膜级 Dice / 端帽 KS | 0.414 / 0.063 | 0.413 / 0.063 |
| 书中没有的字（无真值） | 孔洞一致 145/150 | 145/150 |

> 风格化比例从 90.0% 略降到 88.3%：512 分辨率下拓扑守卫的判定面积阈值更严，多拦下 300 余字。

> 合成字与真迹的轮廓墨量现在基本相等。实际渲染口径两者都是 1.009，肉眼无可辨差别。
