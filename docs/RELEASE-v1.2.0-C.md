# 发布说明：GuanGe Kai C v1.2.0

> 2026-10-30。C 线 v3d2 重切 + 生成模型微调版，接替 v1.1.0。
> 逐字来源、覆盖表、校验和见 `release-c/`。
>
> **三线同步发版**：A 线 **GuanGe Kai v1.7.2**、B 线 **GuanGe Kai B v1.2.4**、
> C 线 **GuanGe Kai C v1.2.0** 同批发布。C 线自身的字体与校验和见 §6；
> A/B 两线的完整性由各自发布流程验证，C 线不代为声明其哈希。

---

## 1. 一句话

v1.2.0 用 **v3d2 全量重切**（两列墨迹中缝 + **每行白廊校验**、`center-gate`/`gap-mid`/`merge-trim`），
并把 v1.1.0 的 ep30 在 **v3c pairs（4,999 对）** 上以 lr 1e-4 微调到 **ep34**；
**v3d2 只用于重切/评估，没有参与本次模型训练。**
真迹 **5,302 字**（基本区 25.26%），GAN 14,752 + 带状回退 938（6.0%），CJK 基本区 20,992 字；另补 **42 个标点/数字/空格**，cmap **21,034**。

## 3. 改了什么

| 问题 | v1.1.0 | v1.2.0 |
|---|---|---|
| 切格 | v2 切（1,187,211 格） | **v3d2 切（1,187,881 格）**：center-gate + gap-mid + merge-trim |
| 形近错切 | `鮓`→魚、`渤`→勃（v3 实验切） | **`鮓`=魚+乍、`渤`=氵+勃**，已复核 |
| 监督信号 | 旧 ep30（v2 pairs） | 旧 ep30 **在 v3c pairs（4,999 对）上 lr 1e-4 微调 4 轮到 ep34** |
| 页留出（模型级） | 0.442 / 6.83 / 15.1% | **0.457 / 6.36 / 11.7%** |
| 300 字留出 | 0.578 / 5.32 / 2.0% | **0.597 / 5.44 / 1.3%** |
| ribbon 回退 | 1,237（7.9%） | **938（6.0%）** |
| 守卫回退字形尺寸 | 455 字约 0.66×（P1） | **按 512 重出，bbox 与文楷同量级** |
| 标点/数字/空格 | 无（cmap 20,992） | **+42，cmap 21,034** |
| 48px 字重 bias | 0.949 | **0.948**（syn 0.705 / real 0.744） |
| a_only | 5.04% | 5.1% |

页留出：Dice **+0.009**、chamfer **−0.20**、崩坏 **−1.0pp**。
300 字：Dice **+0.006**、崩坏 **−0.7pp**，但 chamfer **+0.06**（略差，属噪声量级）。
两项不是全胜；发布依据是“页留出改善 + 崩坏率下降 + 切格缺陷修复”，不是单一 Dice。

**注意口径**：上表的 0.442 是 v1.1.0 模型在 **v3d2 clean** 上的重测值；v1.1.0 在 v2 clean 上的历史值是 0.444。
两套 clean 不同，不能与历史发布数直接混比。

同目标集**字体级**（3,210 字，v1.1.0 vs v1.2.0）：
`0.4844 / 12.19% / 6.518` vs `0.4838 / 12.25% / 6.524`——**基本持平**。
原因：clean 里 98% 是 real，重切只改了少数格子；本版的提升在模型级（GAN 部分）与缺陷/回退率，
不是整体字体级 Dice。见 `work-c/version_compare_v120.json`。

## 5. 已知限制

1. **真迹是 v3d2 新切，但生成模型仍是 v3c-trained ep034**：v3d2 只重切/评估，未重训；
   GAN 字形来自旧模型，严格说不是“用新精选图重训后的模型”。300 格均匀盲审 **20/300 = 6.7%**（Wilson 4.4–10.1%），
   这是本版已知上限，**没有达到 ≤5%**。错标以并格/空/内容错位为主。
2. **v3d2 中缝校验是启发式**：`center-gate` + `gap-mid` + `merge-trim` 靠行白廊/投影；
   极端版面（地图/表格/混排）仍可能误判；`merge-trim` 也可能把并格第二字剪掉。
3. **碎片过滤默认关闭**：v3 的“远组件”规则会删掉 `氵/乍` 这类合法部件，已改为 `--fragment-filter` 可选。
4. 生成模型是**从 v1.1.0 ep30 微调**，不是从零重训；从零 30 轮在 v3d2 上未追上旧模型
   （页 0.431、300 字 0.452），这条负结果保留在 `work-c/logs-v1.2.0/`。
5. 简体码位结构守卫仍有约 30% 的 s2t 字回落 ribbon；本版 ribbon 总占比 6.0%，笔形比 GAN 平。
6. `园`、`四` 的「囗」按写本风格开口（拓扑上无闭合孔），已从 C 线白名单移除并登记。
