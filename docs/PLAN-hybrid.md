# 混合检查点方案（A 线）

> 目标：把 v1.6.3 里 **728 个"原本通过、被加权模型画坏"** 的字捞回来，
> 回退率从 **7.9%** 降到约 **4.1%**，且**不重训**（两个检查点都已存在）。

## 1. 为什么 A 要做、B 可以不做

| | A（四书） | B（史记） |
|---|---|---|
| 加权模型全局表现 | chamfer 5.92→**5.85**（变好） | 5.60→**5.67**（变差） |
| 加权带来的回归 | 728 字被画坏 | 通用质量下降 |
| 混合收益 | **7.9% → 约 4.1%** | 仅约 270 字（1.6%） |
| 结论 | **做** | 可做可不做 |

## 2. 规则（写死，避免"按需挑模型"）

```
对每个合成字 ch：
  1) 用主模型 ep90 生成，过守卫 → 采用（记 gan_ep90）
  2) 否则用副模型 ep80 生成，过守卫 → 采用（记 gan_ep80）
  3) 都不过 → ribbon 回退（记 ribbon_fb）
```

**守卫三条不变**（空输出 / 墨量 [0.6,1.5] / 连通域差 >3）。规则是**确定性**的：
同一个字在同样输入下永远走同一条路径，任何人重跑得到同一结果。

## 3. 预期数字

| 项 | v1.6.3 | 混合后（预期） |
|---|---|---|
| GAN（ep90） | 17,790 | 约 17,062 |
| GAN（ep80 补） | 0 | 约 728 |
| ribbon 回退 | 1,527（7.9%） | 约 799（4.1%） |

## 4. provenance 的四态

现在三态 `real / gan / ribbon_fb`，混合后需要区分补位来源：

```
real        1,675   真迹
gan_ep90    ~17,062 主模型
gan_ep80    ~728    副模型补位
ribbon_fb   ~799    回退
```

`14_package` 的统计要相应改成四态；`stats.json` 增 `gan_ep90` / `gan_ep80` 两个字段。
**兼容性**：旧版三态读取方（若有）看到 `gan_ep90`/`gan_ep80` 不再等于 `gan`，需一并更新。

## 6. 验收（发版前必须全过）

| # | 判据 |
|---|---|
| 1 | 回退率 **< 5%**（预期 4.1%） |
| 2 | `13_qa`：20992/20992、empty 0、real-subset 1675 |
| 3 | **接缝目视**：抽 12 个 `gan_ep80` 字，与相邻 `gan_ep90` 字并排，笔画粗细/风格无可辨差异 |
| 4 | 干净集 chamfer **不劣于 5.85**（混合不改模型，只改选字，理论上应持平） |
| 5 | 打包闸（v1.6.2 加的）通过 |

**判据 3 是关键**：两个模型的输出混在一起，可能出现"某些字偏细/偏圆"的割裂感。
若目视有差异 → 放弃混合，维持 v1.6.3。
