# 发布说明：GuanGe Kai C v1.1.0

> 2026-10-28。C 线质量重做版，接替 v1.0.1。
> 逐字来源、覆盖表、校验和见 `release-c/`。
>
> **三线同步发版**：A 线 **GuanGe Kai v1.7.0**、B 线 **GuanGe Kai B v1.2.2**、
> C 线 **GuanGe Kai C v1.1.0** 同批发布。C 线自身的字体与校验和见 §6；
> A/B 两线的完整性由各自发布流程验证，C 线不代为声明其哈希。

## 1. 一句话

v1.1.0 解决 v1.0.1 遗留的三件事：**单见证真迹偏多**（a_only 12.7%）、
**整体字重比 B 线轻 20%**、**重切后的形近错标**（`讞` 的下坠碎片、`串` 被选成“尚”）。
真迹 **5,295 字**（基本区 25.22%，a_only 5.04%），GAN 14,460 + 带状回退 1,237，覆盖 20,992 字。

## 3. 改了什么

| 问题 | v1.0.1 | v1.1.0 |
|---|---|---|
| a_only 真迹 | 665 / 5,287 = **12.6%** | **267 / 5,295 = 5.04%**（`05 --prefer-ab`） |
| 真迹墨量/文楷（128px 同字） | 0.594 | **0.703**（B 0.730，A 0.835；gain 1.10→1.25） |
| 字体级字重偏差（48px） | 1.046（v1.0.1 口径） | **0.949**（syn 0.709 / real 0.746） |
| 形近错标 | — | 剔除 `讞`（下坠碎片）、`串`（选成“尚”），GAN 补位 |
| 切格代码 | 固定 26–74% 白廊、无碎片过滤 | 两列按墨迹投影定缝、碎片“远+小”过滤（代码就绪；全量 v3 留 v1.1.1） |
| 页留出 Dice / chamfer / 崩坏 | 0.444 / 6.64 / 15.4% | **0.444 / 6.73 / 14.4%**（模型级） |
| 同页字体级 Dice / chamfer / 崩坏 | 0.443 / 6.87 / 16.6% | **0.484 / 6.52 / 12.2%** |
| 按字留出 300 字 | 旧 54 字 0.414（偏置子集） | **0.585 / 5.65 / 1.0%** |

`0.444` 组量的是“同字另一份真迹样本”的风格一致性（98% 是 real）；`0.585` 组量的是
“对干净 medoid 目标的泛化”。两者不是同一任务，A/B 的 0.549/0.523 是 617 个稀有字，
也不能直接比大小。详见 `docs/EXPERIMENTS-C.md` C/E15–C/E30。

## 5. 已知限制

1. **标签来自双引擎一致，未经逐字人工校对。** 两引擎同错的形近字（曰/日、己/已）无法自动发现；
   `串`/`尚` 这类形近错标本轮靠视觉复核抓到，不是自动闸。
2. 合成字不是真迹；严格字形请用 `GuanGeKai-C-Real.ttf`。Real 也经过
   去噪、close 3、补孔、逐字墨量标定，不是原样扫描。
3. **简体码位的结构守衛**：s2t 码位约 **30%** 会回落 ribbon；margin-Dice 判据触发率相同（30%），
   没有减少回落，故保留组件数判据。ribbon 占全字体 **7.9%**，笔形比 GAN 平。
4. **切格的两列中缝与碎片过滤只在代码/抽样层验证**：30 页抽测标签漂移 1.4%，全量 v3 重切
   留 v1.1.1；本版 v1.1.0 仍是旧切 + `讞/串` 黑名单。
5. **墨量标定控制器未完全收敛**：g125 下 76 的 `max_iter` 占 79%、`tol` 19%；
   字体级字重 0.949 已过闸，但逐字面积误差仍可能超过 ±8%。
6. `园`、`四` 的「囗」按写本风格开口（拓扑上无闭合孔），已从 C 线白名单移除并登记。
