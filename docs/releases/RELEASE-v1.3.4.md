# GuanGe Kai v1.3.4

> 两处修正：静默回退从 20.9% 降到 10.0%；合成字墨量改为按笔画复杂度自适应。

**Version 1.3.4** — 20,992 字全覆蓋：1,675 真迹 + 19,317 合成（90.0% 经 ribbon 风格化）。

## 修正的问题

`10_generate.py` 里有一道守卫：ribbon 输出与文楷原样的 IoU < 0.7 时回退成裸文楷掩膜。它的本意是防止渲染崩坏，但实际效果是：

- **被剔除的恰恰是风格化最强的字**——dip 越激进，IoU 越低；
- v1.3.3 的 19,317 个合成字里，**4,043 个（20.9%）是裸文楷矢量化**，没有 dip、没有斜切端头；
- 文档从未披露这一比例，而且所有横向评测都是现场重渲（不经过守卫），
  所以"端帽 KS 0.057"评的是 100% ribbon，发布字体只有 79% 是 ribbon。

## 修正方式

守卫改为「**拓扑不变 或 IoU ≥ 0.7**」：

- 拓扑不变（连通域数与字碗数一致）→ 接受，即使笔画更细；
- 否则退回 IoU 判据；
- 两者都不满足才回退裸文楷。

结果：回退比例从 20.9% 降到 **10.0%**（1,941 字），**2,418 个字重新获得风格化**，
经 ribbon 风格化的比例从 79.1% 升到 **90.0%**。

## 附：墨量按复杂度自适应

v1.3.3 用全局 `scale=0.78`。但刻本的墨量随复杂度变化，在 1,675 对真迹上拟合得
`墨量比(刻本/文楷) = 20.619 × 文楷墨量^-0.330`（简单字 0.99、密集字 0.76）。
全局缩放导致简单字偏细、密集字偏重。现按每个字的文楷墨量逐字定 scale：

| 文楷墨量 | 真迹/文楷 | 全局 0.78 | 按复杂度 |
|---|---|---|---|
| 8k | 0.978 | 0.893（−8.7%） | 0.998（+2.1%） |
| 12k | 0.880 | 0.887（+0.8%） | 0.928（+5.4%） |
| 16k | 0.813 | 0.911（+12.1%） | 0.903（+11.0%） |
| 20k | 0.816 | 0.923（+13.1%） | 0.879（+7.8%） |
