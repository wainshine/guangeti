# GuanGe Kai v1.5.2

> **字形与 v1.5.1 相同。** 这一版是研究结论与工具链的更新。

**Version 1.5.2** — 20,992 字全覆蓋：1,675 真迹 + 17,484 GAN + 1,833 ribbon 回退。

## 结论更新

| # | 结论 | 依据 |
|---|---|---|
| 1 | **加训无增益**：80 轮与 150 轮在干净集上完全持平（Dice 0.543–0.548 vs 0.549，chamfer 5.87–5.94 vs 5.92） | E36，6.5 小时、15 个快照 |
| 2 | **「模型欠训」假设作废**：valDice 在 ep60 见顶后进入 0.59–0.62 平台，此前"ep80 还在涨"是对末两点的过度解读 | E36；E32 的 ep20/ep40 两个数曾与训练日志不符，已按日志更正 |
| 3 | **17% 字重偏差的构成变了**：5–7% 是字集构成（不是缺陷），约 5% 来自模型输出字面偏小（包围盒是真迹的 0.949） | E34 + E37 |
| 4 | **「potrace 膨胀」不成立**：轮廓面积 / 掩膜面积 = 0.9997，没有膨胀可补 | E37；此前的 +13% 是把洞当正面积求和的错误 |

**因此：轮廓层面积补偿这条路已关闭。** 要修字重只能改模型（尺寸一致性）或归一化策略。

## 工具链更新

| 项 | 变化 |
|---|---|
| `--method gan` 推理分辨率 | 改为**训练分辨率 256** 推理，再放大到 `--res` 供矢量化。成品几乎不变（轮廓面积比 0.994），推理快约 4 倍 |
| `--save-every` 默认值 | 5 → **10** |
| 检查点保留规则 | 最终一轮 + 验证最佳 + **核心轮次 50/100/150/200/300/400/500…** |
| `34_struct_score.py`、`35_threshold_sweep.py` | 默认检查点指向已删文件，改为 `m2_ep080.pt` |

## 已知限制（与 v1.5.1 相同）

- 合成字比真迹重约 17%（其中 5–7% 是字集构成）。
- 骨架 chamfer 5.92px vs 真迹互比地板 5.16px。
- 9.5% 的字走 ribbon 回退，集中在复杂字。
- 未做 hinting。
