# GuanGe Kai v1.5.1

> **字形无变化。** 这一版修的是发布卫生与一处**错误的公开披露**。

**Version 1.5.1** — 20,992 字全覆蓋：1,675 真迹 + 17,484 GAN + 1,833 ribbon 回退。

## 改了什么

| # | 改动 | 影响 |
|---|---|---|
| 1 | **逐字来源从两态改为三态**：`real` / `gan` / `ribbon_fb` | 之前 1,833 个回退字混在 `gen` 里，机器可读的来源表无法区分 90.5% 与 9.5%；现在可查 |
| 2 | **`stats.json` 修正**：`generated` 从 0 改为 19,317，并新增 `gan` / `ribbon_fallback` 两个字段 | 上一版包内统计写着「合成 0 字」，与实际严重不符 |
| 3 | **更正小字号披露** | 见下节；上一版写「12–14px 偏重 12–20%，16px 起持平」，**结论错误** |
| 4 | 文档结构整理：版本记录统一由新到旧、实验编号补全至 E34、工作区残留表与磁盘对齐 | 不影响字体 |

## 更正：小字號偏差（E34）

上一版说合成字在 12–14px 偏重、16px 起趋于一致。三种口径重测后**不成立**：

| 口径 | 结果 |
|---|---|
| A 同字掉墨率（缩到 S px 与 96px 的墨量比） | 真迹 0.016 vs 合成 0.015（12px）——**两组一致** |
| B 跨组墨量比（合成中位 / 真迹中位） | 12px 1.161、16px 1.178、32px 1.173、96px 1.158 ——**全字号恒定** |
| C 相对文楷 | 真迹 0.75–0.87、合成 0.83–0.94 |

**正确说法：合成字比真迹重约 17%，与字号无关。** 上一版的错误来自统计方法
（把两组独立样本的比值数组逐元素相除再取中位），已记录在 E34。

其中 **5–7% 来自字集构成**（合成字多为生僻字，本身墨就多）；逐字比对可见模型输出是准的
（合成/真迹 0.995）。剩余约 7.6% 出在描摹与归一化环节，**不是一个可以一键乘上去的常数**
（E35 已排除"推理分辨率"这一假设）。修法需要在轮廓层做面积补偿，留待后续版本。
