# GuanGe Kai B v1.0.0

> 随主版本 **GuanGeKai v1.6.0** 发布。同一项目、两个字形来源：
> A = 四书刻本《四書白文》（家族名 `GuanGe Kai`，v1.6.0）；
> B = 史记抄本（家族名 `GuanGe Kai B`，本包 v1.0.0）。
> 两套家族名并存，安装后互不覆盖；A 线的字形本次未变更。

**Version 1.0.0** — 首个版本。CJK 基本区 **20,992 字全覆盖**：
真迹 4,065 + GAN 生成 15,838 + ribbon 回退 1,089（共 20,992）。字型内另含 5 个扩展 A 的真迹字（已列入 provenance），
故 cmap 共 20,997 个码位。

## 孔洞（counters）修复

审计 rev2 的 P0：常用字曾被渲染成实心（`四/目/自/年/见/具`）。原因是扫描笔画边缘的
1–2px 细缝让孔连到外面，二值化阶段孔就已不存在。修法是在追踪前做 **7px 形态学闭运算**：

| 字体 | 孔洞完全丢失（修前 → 修后） | 孔数一致（修前 → 修后） |
|---|---|---|
| `GuanGeKai-B-Real.ttf`（2,937 可比字） | **15.8% → 4.1%** | 27.6% → 35.4% |
| `GuanGeKai-B-Regular.ttf`（300 抽样） | 8.9% → **5.6%** | 26.6% → 35.0% |

字重只增加 1.8%（ink/文楷 0.758 → 0.772）。**合成字仍有残留**：GAN 的训练目标本身
来自填实的掩膜，模型学会了画实心孔，闭运算只能救回边缘细缝——彻底修复需要重切掩膜
+ 重训，列为 v1.1 首要项。

## 已知限制

- **常用字的孔洞（counter）仍有残留**：本版修掉了大部分（真迹完全丢孔 15.8% → 4.1%，
  全字体 8.9% → 5.6%），但**约 5.6% 的可比字仍比文楷少孔**，其中合成字受影响更大——
  因为 GAN 的训练目标来自填实的掩膜。彻底修复需要重切掩膜 + 重训（v1.1）。
- **1,089 个字（6.4%）走 ribbon 回退**，集中在复杂字。ep80 相比 ep50（9.3%）少了 478 个回退字。
- **合成字比真迹重约 12.5%**：掩膜层 +0.8%、包围盒偏大 +6%、其余约 5% 未拆开。
  四书线是 +17%，但那套归因在 B 线不成立（B 线包围盒偏大而非偏小）。
- **崩坏率 2.9%**（Dice < 0.30），高于四书线 0.7%。
- chamfer 5.57 低于四书线 5.92，但相对各自地板仍是 56%（四书 15%）。
- 十篇「表」（卷十三–二十二）在参考文本里是表格结构，该 12 页不进入真迹字表。
- 未做 hinting；小字号依赖系统自动微调。
