# GuanGe Kai v1.6.4（A 四书）

> **回退率从 7.9% 降到 4.1%**：用「混合检查点」把 v1.6.3 里被加权模型画坏的 728 个字捞回来。
> 这是本项目第一次让一个字体的合成字来自两个模型。

## 本版变更

| 项 | 内容 |
|---|---|
| **混合检查点**（E40） | 主模型 `m2wt_ep090` 生成；被守卫拦下的字改用 `m2_ep080` 再试；都拦才回退 ribbon |
| **回退率** | 7.9%（1,527）→ **4.1%（799）** |
| **构成** | `gan_ep90` 17,790 + `gan_ep80` **728** + `ribbon_fb` 799 |
| **墨量对齐** | 补位模型用阈值 **−0.45** 标定，墨量比 1.001 vs 主模型 1.041（差 3.8%） |

## 为什么需要标定阈值

ep80 是未加权模型，对复杂字画得保守——直接用它补位，墨量比只有 0.932，与主模型的 1.041 差 10.9%，
混排会有可见的粗细波动。实测扫描后取 **−0.45**：

| 阈值 | gen80 墨量比 | 与主模型差 |
|---|---|---|
| −0.05（默认） | 0.932 | −10.5% |
| −0.30 | 0.972 | −6.6% |
| **−0.45** | **1.001** | **−3.8%** |

## provenance 四态

逐字来源现在区分两个模型：

```
real       1,675
gan_ep90  17,790   主模型（加权）
gan_ep80     728   补位（阈值 −0.45）
ribbon_fb    799   回退
```

`stats.json` 相应增加了 `gan_ep90` / `gan_ep80` 两个字段。

## 已知限制

1. **孔洞缺陷**：`四/国/目/自/年` 等字仍实心（lost 1.9% / fewer 28.5%，与 v1.6.3 持平）。
   E38 已证明高 dpi 只能恢复 22% 的缺孔字，多数是原书断笔，无工程解法。
2. 合成字比真迹重约 17%（E34/E37 已拆解成因）。
3. **混排的细微粗细差**：补位字与主模型字之间仍有 3.8% 墨量差，正常阅读看不出来，
   但极端情况下（连续多个补位字）可能有轻微波动。
4. 未做 hinting。
