**Version 1.5.0** — 20,992 字全覆蓋。

## 字库构成（三层）

```
20,992 字
├─ 1,675  真迹   直接取自刻本，不经过任何模型
└─ 19,317 合成
   ├─ 17,484  GAN（m2-ep80）     90.5%
   └─  1,833  ribbon 回退         9.5%   ← 守卫判定 GAN 输出不可靠
```

**有真迹的字一定用真迹。** GAN 只负责书中没有的字；GAN 输出触发守卫时退回 v1.3.x 的带状扫掠。

## 为什么换

v1.3.5 的合成字骨架取自霞鹜文楷，**结构就是文楷的结构**；而文楷与刻本真迹的拓扑一致率只有 47%，
笔画级差异（横画更斜、字碗不同）是渲染器改不掉的（E21/E28）。

GAN 直接学「文楷渲染 → 刻本字形」的映射，学到的是笔画级的形，不只是笔形参数。

## 模型

| 项 | 值 |
|---|---|
| 架构 | zi2zi U-Net + **PatchGAN 判别器（5 层，≈70×70）** |
| 损失 | hinge 对抗 + L1×100 + 常数项×15 |
| 训练数据 | 1,634 对（单实例，每字一张中位样本） |
| 增强 | ±2° 旋转、±3px 平移、0.95–1.05 缩放（X/Y 同步）——**本项目首次启用** |
| 轮数 | 80 轮（3.5 小时），验证曲线到 ep80 仍在上升 |
| 检查点 | `work/ckpt/m2_ep080.pt` |

## 生成时的守卫

三个廉价判据，任一不满足就整字回退 ribbon：

```
空输出 / 墨量比不在 [0.6, 1.5] / 连通域数与文楷相差 >3
```

全量触发 **1,833 字（9.5%）**，偏向复杂字（回退字平均墨量 13,695 vs GAN 字 12,479）。

> 这不是 v1.3.x 那个「字碗数必须等于文楷」的闸门——那个会回退 85%（E24）。

## 已知限制

- **合成字整体偏重约 17%**：12px–96px 全字号恒定（E34 三种口径：同字掉墨率两组相同、
  跨组中位数之比 1.16–1.20、相对文楷 1.10）。这是**固有墨量差**，不是小字号效应。
  下一版可做全局标定修正。
- **9.5% 的字仍是 ribbon**，它们与 GAN 字在极近距离下可能有细微风格差。
- 训练验证曲线到 ep80 仍在上升，**模型未训到头**。
- 未做 hinting。
